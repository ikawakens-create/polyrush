# ADR-0017: 非自明性メトリクスの計測専用層 (PuzzleMetrics) の導入

- Status: Proposed (2026-06-20)

## Context

### 解決したい問題
非自明性は ADR-0012 判断6・ADR-0013 判断6 で繰り返し「別軸であり対象外」として
先送りしてきた。コンパクト化（充填率）が V3 で一段落した今、これに着手する。

ねらいは、生成されたパズルが「一目でピース境界が分かる自明な問題」か
「考えないと解けない非自明な問題」かを数値で観測できるようにし、将来は
生成段階で自明な問題を避けられるようにすることである。

### 重要な前提（本セッションの気づき・記録）
本物のウボンゴの面白さの芯は、手元のピースを頭の中で回転・反転させて
「どこにどう嵌るか」を探す空間推理にある。現行ゲームには回転・反転の操作が無く、
ピースは解の向き（orientation）のままトレイから手渡される。このため
枠の形だけで生み出せる非自明性には上限がある。

回転・反転の導入は、操作UI・トレイ・配置判定・手触り（snapRadius）・保護対象に
広く及ぶ大改修であり、独立した別 ADR で扱う。本 ADR の対象外とし、
最大の申し送り事項として記録する。非自明性メトリクスは、回転・反転を
導入したあとに本領を発揮する土台と位置づける（枠の非自明性 → 回転・反転 →
噛み合い／風車が真に効く、という積み上げ）。

### 制約
- 生成器（CompactPuzzleGeneratorV3 ほか）・ソルバ（PuzzleSolver）・配置判定等は
  CLAUDE.md 禁止リストにより変更禁止。
- 座標系は (y, x) = (row, col)（ADR-0006）。
- 計測は Code Web のローカル実行に依存させず CI テストで行う（恒久ルール⑤）。

## Decision

### 判断1: 計測専用の新モジュールを追加（B案踏襲）
新ファイル lib/domain/puzzle/puzzle_metrics.dart を追加する。既存ファイルは
一切変更しない。GeneratedPuzzle を読むだけの純粋関数群として実装する。
ADR-0008 以降の「確定資産を改造せず外側に足す」方針を踏襲する。

### 判断2: 第1PRは「測るだけ」。生成器には組み込まない（2段構え）
非自明性の正解は主観的（人がそのパズルを難しいと感じるか）であり、機械の指標が
人の感覚と一致するかを先に確かめる必要がある。よって本 PR は生成へ一切手を入れず、
多数 seed で計測して CI に結果を出力するに留める。較正の後、別 PR で生成へ
組み込む。これは ADR-0010 判断5「まず本丸 → 効果確認 → 次」の思想を踏襲する。

### 判断3: 単一の合成スコアは本 PR では確定しない。複数の指標を併記する
設計の過程で「配置の回転対称性だけ」では自明な行分割（横棒4本）も 180°対称に
なり、非自明な風車と区別できないことが判明した。よって単一の formula を早期に
固定せず、互いに性質の違う複数指標を出力して較正に用いる。合成スコアの確定は
較正後の別 PR とする。

### 判断4: 本 PR で計測する指標（PuzzleMetrics）
- rotationalSymmetry90 (double?): 正方形枠のときの 90°回転対称度。真の風車検出。
  横棒分割は 0、完全な風車は 1.0。非正方形枠では null。
- rotationalSymmetry180 (double): 180°回転対称度。文脈用。横棒も風車も高くなり
  単独では非自明性を測れないため、主指標にはしない。
- straightCutSeparable (bool): 枠を縦横いずれかの直線1本で、どのピースも
  跨がせずに2つの非空領域へ分割できるか。true なら独立した小問題に分解でき自明
  （横棒・縦棒の自明さを捉える、sym90 と相補的な主指標候補）。
- protrusionRatio (double): 枠セルのうち、隣接する枠セルが1以下の「しっぽ／突起」
  セルの割合。高いほど強制配置が多く自明（ADR-0012 が指摘した細いしっぽ・
  1マス突起に対応）。
- fillRatio (double): 枠セル数 / 外接矩形面積（既出の充填率概念）。
- orientationUsageRatio (double): 解で source と異なる向き（orientation）を使った
  ブロックの割合。本セッションの気づき（解が回転・反転を要するか）を直接定量化する。
  実験的指標として併記し、向きの意味づけはサンプル出力で検証する。
- pieceCount (int): ピース数。

### 判断5: 計測は CI テストで実施し、ASCII アート付きレポートを出力（恒久ルール⑤）
難易度ごとに多数 seed（既定: easy / normal / hard 各100件、計300件目安）で
CompactPuzzleGeneratorV3 の本番経路から生成 → 計測し、各指標を表形式で出力する。
加えて、非自明性が高い／低い代表パズルを数件、ピースを表す文字の ASCII アートで
出力し、井川が「指標と見た目の難しさが一致するか」を目視で較正できるようにする。
レポートテストは生成成功のみを hard assert し、指標値は出力に徹する。

### 判断6: 較正後に PR#2 で生成へ組み込む
井川と Opus がレポートを見て、人の感覚と一致する指標（または合成）を決め、
別 PR で「自明な問題を避ける／非自明な問題を選ぶ」生成フィルタとして組み込む。
本 ADR の範囲外。

### 判断7: 回転・反転の欠如をウボンゴとの最大差として記録（申し送り）
上記 Context のとおり。回転・反転の導入は独立 ADR で設計する。

## Consequences

### ポジティブ
- 確定資産を一切変更しない、最小リスクの PR。
- 非自明性を初めて数値で観測できる。
- 回転の要否（orientationUsageRatio）を定量化し、次の大仕事（回転・反転導入）の
  根拠データが残る。

### ネガティブ
- 単独で「非自明性スコア」を即座に生成へ使えるわけではない（較正の1往復が要る）。
- 風車（sym90）は正方形枠でしか定義されず、多くのパズルで null になる見込み。
  ただしそれ自体が「現生成器は風車をほぼ作らない」という有用な観測になる。
