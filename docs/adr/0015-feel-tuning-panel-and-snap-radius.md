# 0015 手触り調整パネルと snapRadius 確定値

- Status: Accepted
- Date: 2026-06-11

## Context

子供の実機テストで「ブロックをマスに嵌めるときの吸着が弱い」という
フィードバックが出た。調整にあたり、前セッションの Opus が play_screen.dart に
仕込んでいた「手触り調整パネル」の存在が引き継ぎメモから漏れており、
仕組みの再調査が発生した。再発防止のため、パネルの存在と snapRadius の
確定値・根拠を記録する。

## Decision

### 1. 手触り調整パネル（隠しデバッグUI）の仕様を記録する

- 場所: lib/ui/screens/play/play_screen.dart の _openSettingsPanel()
- 開き方: プレイ画面のタイトル「PolyRush（プレイ）」を 0.8 秒以内に 5 回連続タップ
- 内容: FeelConfig の全フィールド（fingerOffset / snapRadius / pickupRadius 等）を
  スライダーでその場調整できる。コード変更・再ビルド不要で実機で値を探れる。
- 用途: 手触り系の数値は「実機スライダーで探る → 決まった値を feel_config.dart の
  デフォルトに焼く小 PR」の 2 段で確定させる。これを今後の標準手順とする。

### 2. snapRadius を 0.5 から 0.71 に確定する（PR #79）

- snapRadius は「ボードのマスにピースを嵌めるときの吸着オンオフのしきい値」。
  単位はセル（格子交点からのズレを cellSize=1.0 として正規化したユークリッド距離）。
- 吸着先のマスは常に「最寄りの格子に .round() で丸める」方式で決まる。
  snapRadius は「吸うか吸わないか」だけを決め、「どのマスに吸うか」には影響しない。
- したがって snapRadius を上げても隣マスに誤吸着することはない。
  上限は対角方向の最大ズレ √(0.5²+0.5²) ≈ 0.707。0.71 で「吸わない領域」が消え、
  これ以上の値は挙動が変わらない（実質マックス）。
- 子供の実機テストで 0.71 を採用。控えめでなく、しっかり吸う方向の要望に合致。

## Consequences

- 手触り調整は再ビルドなしで実機で探れる手順が確立した。
- snapRadius は実質マックスの 0.71 で確定。以降この値の再調整は基本不要。
- snapRadius は FeelConfig（feel_config.dart）に集約されており（ADR-0014）、
  本判断は設計意図どおりの定数調整である。placement_logic.dart 等の保護対象は
  一切変更していない。
